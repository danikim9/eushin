How it works

보호자는 단어만 넣어 주세요

학교나 학원에서 받은 이번 주 단어를 넣으면, 모든 게임이 그 단어로 바뀌어요.

이번 주 단어 넣기

단어 10개와 짧은 문장 2개를 적어요. 자주 쓰는 단어는 그림이 자동으로 붙고, 학습지 사진에서 복사한 글자를 붙여 넣으면 단어를 찾아줘요.

게임으로 연습하기

보고 듣고 따라 말한 뒤, 철자 맞추기 → 단어 놀이 → 문장 만들기로 이어가요. 틀려도 혼나지 않고, 힌트를 받아 다시 도전해요.

별 모아 탐험하기

맞힐 때마다 별을 받고, 실수 없이 끝내면 보너스 별까지. 별이 모이면 새로운 장소에 도착하고 배지를 받아요. 탐험은 끝없이 이어져요.

인터넷 없이도

홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 돼요.

🔒

보호자 메뉴 잠금

단어 바꾸기와 설정은 곱셈 문제를 풀어야 열려서 아이가 실수로 바꾸지 않아요.

홈 화면에 추가하기

앱 스토어 없이, 브라우저에서 한 번만 추가하면 앱처럼 전체 화면으로 열려요. 한 번 연 뒤에는 인터넷 없이도 쓸 수 있어요.

앱 열기 ›

아이폰 · 아이패드 Safari

  1. Safari에서 www.spelly.kr/app을 열어요.
  2. 공유 버튼을 눌러요. 아이패드는 주소창 오른쪽, 아이폰은 화면 아래에 있어요. 안 보이면 ··· 메뉴 안에 있어요.
  3. 목록을 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누르면 Spelly 아이콘이 생겨요.

안드로이드 Chrome

  1. Chrome에서 www.spelly.kr/app을 열어요.
  2. 오른쪽 위 메뉴를 눌러요.
  3. 홈 화면에 추가 또는 앱 설치를 누르고, 설치를 누르면 Spelly 아이콘이 생겨요.

삼성 인터넷은 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 눌러요. Spelly 앱의 보호자 메뉴에서 지금 설치하기 버튼이 보이면 그걸 눌러도 돼요.
