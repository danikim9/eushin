## 첫 게시물 (캐러셀 5장, 1080×1350)

`post1-1.png` ~ `post1-5.png` 순서대로 올려요. 이미지는 `node render.mjs slides.html post1`로 다시 만들어요.

1. 표지: 이번 주 영어 단어, 이제 놀이로 외워요
2. Spelly는 이런 놀이예요: 학교 단어 그대로 · 16가지 게임 · 별 모아 탐험
3. 아이 혼자서도 할 수 있어요: 소리로 읽어 줘요 · 틀리면 힌트 · 맞히면 칭찬
4. 아이가 고르는 4가지 세상
5. 보호자는 단어만 붙여 넣으면 준비 끝 · www.spelly.kr

## 두 번째 게시물: 보호자 할 일은 딱 1분 (캐러셀 5장)

`post2-1.png` ~ `post2-5.png`. 이미지는 `node render.mjs slides2.html post2`로 다시 만들어요.

1. 표지: 보호자 할 일은 딱 1분이에요
2. 학습지 사진에서 글자를 길게 눌러 전체 선택 → 복사
3. 보호자 메뉴에 붙여 넣고 Find words
4. 단어·뜻·문장, 그림까지 자동으로 채워짐
5. 마무리: 보호자는 1분, 나머지는 Spelly가

```

1️⃣ 학습지 사진을 열고 글자를 길게 눌러
   전체 선택 → 복사
2️⃣ Spelly 보호자 메뉴에 붙여 넣고 [Find words]
```
