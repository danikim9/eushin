## 보이스오버 넣기

대본을 TTS(일레븐랩스 등)로 만든 뒤 위 시간에 맞춰 한 파일로 이어 `vo.wav`(44.1kHz)로 두고:

```sh
ffmpeg -i vo_raw.mp3 -ar 44100 -ac 1 vo.wav
python3 audio.py      # vo.wav 가 있으면 얹고, 말하는 동안 음악을 낮춤
node render.mjs       # 또는 영상은 그대로 두고 오디오만 교체:
# ffmpeg -i spelly_reel.mp4 -i audio.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k out.mp4
```

## 다시 만들기

1. 저장소 루트에서 `node build.mjs && python3 -m http.server 8765`
2. 이 폴더에서 `node footage.mjs` — 앱을 1024x768(1.5배)로 한 번에 녹화해 `footage/`(30fps jpg)와 `marks.json`(장면 시작 시각)을 만듦. Supabase 는 막고 기기 저장 모드로 돌림.
3. `python3 audio.py && node render.mjs` — `promo.html` 의 `render(t)` 를 프레임마다 캡처해 `spelly_reel.mp4`. 스틸만 보려면 `node render.mjs --stills 1.9,8.0,21.8`.

장면 시간을 바꾸면 `promo.html`(layerWin·FLASHES·SHAKES)과 `audio.py`, 이 README 표를 같이 옮길 것. 폰트는 Pretendard(OFL).
