## 다시 만들기

1. 저장소 루트에서 `node build.mjs && python3 -m http.server 8765`
2. 이 폴더에서 `node footage.mjs` (앱 녹화, `footage/*.jpg`와 `marks.json`), 이어서 `ffmpeg -framerate 30 -i footage/%05d.jpg -c:v libx264 -crf 14 -pix_fmt yuv420p footage.mp4`
3. 로고 PNG: `mark.svg`를 1024px `mark.png`로 저장
4. 음악과 영상:
   ```sh
   mkdir -p out && python3 music.py 24.0 0 30 31 out/music.wav 120
   ffmpeg -i out/music.wav -af "lowpass=f=8000,aecho=0.8:0.5:50|100:0.2|0.1,loudnorm=I=-18:TP=-2" -ar 44100 out/music_fx.wav
   python3 build_themes.py
   ```
5. 보이스오버: 녹음한 파일을 위 시작 시각에 맞춰 `vo.wav`(44.1kHz)로 두고 `python3 build_themes.py`를 다시 돌리면 얹고, 말하는 동안 음악을 낮춰요.

폰트: NanumSquareEB / NanumSquareRoundEB (`apt-get install fonts-nanum fonts-nanum-extra`).
